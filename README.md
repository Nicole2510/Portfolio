## Highlights

- Showcases my work experiences
- Featured software, AI, desktop, FPGA, and embedded systems projects
- Technical skills presented with recognizable technology logos
- Responsive light and dark themes
- Interactive bookshelf and draggable interests section
- Downloadable resume

## Built With

- React
- TypeScript
- TanStack Start and TanStack Router
- Tailwind CSS
- Vite
- Radix UI

## Run Locally

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local address shown in the terminal, usually `http://localhost:8080`.

## Production Build

```bash
npm run build
```
